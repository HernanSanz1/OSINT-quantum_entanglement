# Contribuyendo

¡Gracias por tu interés en contribuir a este proyecto! 

## Proceso de Contribución

1.  **Fork** este repositorio.
2.  Crea una rama para tu cambio (`git checkout -b feature/mi-nueva-caracteristica`).
3.  Haz tus cambios y **commit** (`git commit -m 'feat: añadir nueva característica'`).
4.  Haz **push** a la rama (`git push origin feature/mi-nueva-caracteristica`).
5.  Abre un **Pull Request**.

## Reglas Clave

-   Mantén el código limpio y comentado donde sea necesario.
-   Asegúrate de que tus cambios no rompan la funcionalidad existente.
-   Usa "Conventional Commits" para tus mensajes (ej: `feat:`, `fix:`, `docs:`).
-   Actualiza la documentación si cambias el comportamiento del código.
